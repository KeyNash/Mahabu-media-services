# Mahabu Media Services

A static, responsive media-studio website built with semantic HTML, modern CSS, and dependency-free JavaScript.

## Local preview

```powershell
python -m http.server 4174
```

Open `http://127.0.0.1:4174/`.

## Structure

- `index.html` — semantic content and metadata
- `css/style.css` — responsive design system
- `js/main.js` — navigation, progressive reveal, and local brief generation
- `images/` — original brand/capability assets and an optimized logo copy
- `docs/` — audit, verification, screenshots, and portfolio record

## Project brief behaviour

The form creates a structured brief entirely in the visitor's browser. It does not send or store personal information. The visitor can copy the output and share it through a confirmed Mahabu contact channel later.

## Publication status

The website intentionally excludes unverified metrics, testimonials, contact details, social accounts, pricing, and client-project claims. Before publication, Nash must confirm the project classification, role, contact channels, operating region, service scope, and permission to publish the current imagery.

Add canonical metadata, an absolute social image URL, sitemap URL, and final structured-data URL after choosing the production domain.
